# Sistema-Gerenciar-V-os

## Sobre o projeto

Aplicação desktop C# com Windows Forms e .NET Framework 4.7.2. Inclui telas de gerenciamento de aeronaves e pilotos e um conjunto de dados tipado.

## Como explorar

Abra `WfaDS.sln` no Visual Studio no Windows, com suporte a .NET Framework 4.7.2 e Windows Forms. Revise a configuração do conjunto de dados e a conexão do ambiente antes de executar.
